# USB 调试使用说明

用桌面浏览器，经 USB 查看和修改一块已经刷入兼容固件的 ESP32-C3。不需要 Home Assistant，也不需要 Wi-Fi。

[English](./WEB_CONSOLE.md)

这里只写页面现在已经做到的事。软件能走通、真机做过、允许发布，是三件不同的事。本说明哪一件都不是。

## 你现在可以做的事

1. 在桌面 Chrome 或 Edge 里选择雷达和主控，并确认接线。
2. 若发布列表里有兼容固件，页面校验清单通过后才允许烧录。没有可用版本时，说明仍然可读，烧录按钮保持关闭。
3. 关掉安装窗口，等到端口空闲，再手动连接 USB 调试。
4. 看协议是否在线，以及设备报告的型号和有效观测。
5. 改一项配置，先在设备上验证，再保存，并读回。
6. 导出有限的观测记录或诊断摘要。
7. 需要 Home Assistant 时再按新手指南做。那一步是可选的。

## 支持范围

第一次验证针对 **R60ABD1** 和 **带原生 USB 的 ESP32-C3**。页面也会列出其他已经 Completed、维度是 1D 或 2D、芯片是 ESP32-C3、且 UART 为 GPIO21/GPIO20 的组合。列出来只表示目录里有这项声明，不表示这些组合都已经通过 MWCP 验收。

同名板不都一样。ESP32-C3 Super Mini 的图只对应仓库里的参考布局。USB 转串口桥、别的引脚、别的芯片都不在这次承诺里。YAML 里的 board 名字也不能证明你手里的板子就是那一块。请对照板上的丝印。

雷达串口和浏览器 USB 是两条线：

- 电脑插的是主控的 USB 口。浏览器只打开这一条。打开参数是 115200、8 数据位、无校验、1 停止位。
- 雷达仍接在主控上。GPIO21 是主控 TX，接到雷达 RX；GPIO20 是主控 RX，接雷达 TX。雷达这一侧同样是 115200、8 数据位、无校验、1 停止位。这来自共享的雷达配置，不是本页猜的。
- 不要把雷达的 UART 直接接到电脑。
- 供电和逻辑电平以 [新手上手指南](../GETTING-STARTED_CN.md)、[烧录页维护说明](./FLASHER_CN.md) 和模块手册为准。R60ABD1 的供电证据写在维护说明里。本说明不另给电压或电流。

## 固件：四件事不要混在一起

1. **源码里有这份协议。** 组件里有 mmwave_host。维护者编译用的 host 配置是 tests/r60abd1-esp32c3-host.yaml。它包含 tests/common/r60abd1_mwcp.yaml，并启用 mmwave_host。
2. **某个配置在编译时启用了它。** 只有选用这个 host 配置编译，固件里才会带上 USB 调试协议。文件在仓库里，不等于你的板子上已经有它。
3. **某个镜像实际刷进了板子。** 板子上现在跑的是哪一个文件，只有当时的烧录记录能说明。本说明不补造镜像身份，也不把历史短测写成新的覆盖。
4. **某个版本已经发布。** 页面只相信发布索引和校验过的清单。仓库里的 static/public/releases.json 目前是空列表。对外的 factory 包包含 tests/r60abd1-esp32c3.yaml，那个文件再包含 tests/common/r60abd1.yaml，并不启用 mmwave_host。

因此：需要兼容固件，当前能预览的范围有限。这里不提供下载链接。页面上有烧录按钮，或者仓库里有源文件，都不能当成已经发布了带 MWCP 的固件。没有版本时，页面写“尚无该组合的已发布固件”。这不是烧录成功。

## 打开页面

使用桌面版 Chrome 或 Edge。地址必须是 HTTPS，或者你自己机器上的 localhost。Firefox、Safari 和手机可以看说明，不能打开串口。先关掉其他正在占用这个 USB 口的串口工具，并使用能传数据的 USB 线。

页眉的 **USB 调试** 会滚到控制台。控制台标题下的 **USB 调试使用说明** 打开本文件在仓库默认分支上的副本。正式页面不会出现“模拟页面”这几个字。若你看到“模拟模式”或“回放模式”，那一屏不能当作真实设备通过。

## 在你自己的设备上

下面是使用步骤，不是允许任何人现在去烧录或打开某个串口。

1. 打开页面，选择 **R60ABD1**。
2. 选择主控。参考组合是 **ESP32-C3 Super Mini**。对照丝印，勾选已经核对接线。
3. 进入固件一步。有兼容 Beta 时，页面先显示“正在校验固件清单…”。校验通过后，**连接设备并烧录** 才可用，并使用这份清单。Alpha 不会被自动选中。要试 Alpha，必须自己选中，并勾选风险确认。
4. 清单不可用、版本对不上或校验失败时，烧录保持关闭，并提示已禁用烧录。不要换成来路不明的文件。
5. 烧录在浏览器的安装窗口里完成。完成后关闭该窗口，等到不再提示占用，再手动连接。关闭窗口不等于端口已经释放。若仍提示占用，等几秒再试。页面不会自动接管，也不会因为窗口关了就显示烧录成功。
6. 在 **USB 调试** 里点 **连接设备**，在系统对话框里选择主控的 USB 口。点取消不是故障，可以再点一次。
7. 协议显示在线后，看设备报告的 configured_model、维度和固件版本。这个型号来自固件配置，不是从 USB 编号猜的。它和页面选型不一致时，页面使用设备报告的型号，不会自动改烧录目标，也不会自动烧写。
8. 在 **快速验证** 或 **实时数据** 里看有效样本。未知、已过期、历史样本都不是“无人”。坐标是 0，或者目标列表是空的，也不能自己推断成无人。只有设备明确给出的存在样本才算。
9. **生命体征（非医疗用途）** 只在设备声明了该能力、并且样本有效时显示数值。没有声明就不显示数值。这些数字不能用于医疗判断。
10. 打开 **配置**。改一项，点 **在设备上验证**，看将要写入的变化，再点 **保存到设备**。完整成功的提示是 **已保存并读回**。然后点 **断开**。

## 五层状态分别是什么

- **串口**：浏览器有没有打开 USB 口。打开不等于协议已经通。
- **协议**：MWCP 握手有没有完成。在线才表示这次会话还活着。
- **雷达**：主控和雷达之间的通信，由设备报告。协议在线不能代替它。
- **数据**：当前有没有可用观测。历史样本会单独标明，不是此刻的人。
- **配置**：当前能不能读或写配置。读失败不是保存成功。

存在只有设备自己的说法才算数：未知、已过期、不支持、报告无人、报告有人。这些词不能互相顶替。无人只在设备明确这样报告时出现。

## 配置怎么保存

编辑先留在这一个浏览器标签的内存里。验证和保存是两次操作。

- 没有改动时，保存不可用，页面写“没有未保存的修改”。
- 保存时只提交你改过的项。
- **已保存并读回** 才是这一次保存的完整成功。
- **保存已确认，读回失败，请重读** 表示设备接受了写入，但页面还没重新读到结果。点 **重新读取设备**。不要把它当成已经核对完成。
- **读取没有完成。这不是保存确认** 只是普通读取失败，可以重试读取。
- 设备上的配置被别的入口改过时，页面保留草稿，保存关闭，并要求先 **重新读取设备**。新读到的值只供对照，不会自动覆盖草稿。重新读取之后，再决定要不要重新编辑并提交。
- **保存结果待确认** 表示这一次写入没有明确结论。原来的操作可能已经写进设备。请留在页面上点 **查询原保存**，或断开后重新连接再查询同一次操作。不要立刻再保存一遍，不要刷新当作取消，也不要把断开当成取消。
- 关闭浏览器后，这条待确认记录会从内存里消失。本页不承诺刷新之后还能接着查同一次操作。
- **放弃跟踪** 只是让本页停止查询。它不表示原来的写入没有发生。

## 烧录和调试不要同时占着端口

USB 调试正在连接、占用或释放端口时，**连接设备并烧录** 不可用。页面会说明：关闭安装窗口不等于端口已经释放。先点 **断开**，等到 **连接设备** 重新可点，再烧录。

端口关闭失败时，断开按钮还在，页面写“端口关闭失败，仍然占用”。可以重试断开。不要把它当成已经空闲。

安装窗口还在时不要连接调试。窗口从页面上消失后，页面只提示你手动连接，不会自动打开端口。

## 遇到问题时

| 你看到的 | 下一步 |
| --- | --- |
| 已取消选择端口 | 再点一次 **连接设备**，选主控的 USB 口。这不是雷达坏了。 |
| 不能使用 Web Serial，或页面不在安全上下文 | 改用桌面 Chrome 或 Edge，并用 HTTPS 或 localhost 打开。手机只能看说明。 |
| 安装窗口正占用，或正在释放端口 | 先关掉安装窗口，等到提示消失。不要连续点连接或烧录。 |
| 端口关闭失败，仍然占用 | 再点一次 **断开**。仍然失败就拔掉 USB，关掉其他串口程序后再插上。 |
| 未收到控制台协议响应 | 确认固件带 MWCP、选的是主控 USB 口、设备已经启动完。这不能说明雷达硬件损坏。当前公开的 factory 镜像默认不带这个协议。 |
| 会话已过期 | 点 **在当前端口重新握手**。页面不会自动重连，也不会趁机再写一次。 |
| 历史样本，或已过期 | 重新连接后再看。不要把旧样本当成现在无人。 |
| 设备配置已被其他入口修改 | 草稿还在。先 **重新读取设备**，对照后再决定是否提交。 |
| 保存结果待确认 | 点 **查询原保存**，或重连后查询。不要再保存一次，也不要刷新。 |
| 清单校验失败，或尚无已发布固件 | 烧录保持关闭。等维护者发布兼容版本。不要把按钮或空列表当成烧录成功。 |

## 记录和诊断

在 **实时数据** 里点 **开始记录**。要留下文件，在记录还在的时候点 **导出 JSONL** 或 **导出 CSV**。点 **停止记录** 会清空本页内存里的记录。关闭或刷新页面也会丢掉还没导出的内容。内存最多保留最近 600 条，更早的会被丢掉；记录不会因此自己停下来。

导出会去掉字段名像密码、令牌或 secret 的值。目标序号不是同一个人的持续身份。

**诊断** 里的 **导出诊断摘要** 默认不写 SSID 和 IP。勾选“在导出中包含 SSID 和 IP”也仍然不包含密码。摘要只有有限的近期日志，不是完整通信记录。生产页面按硬件模式连接，不会把模拟标成真机。

## Home Assistant 是后一步

USB 验证不依赖 Home Assistant，也不依赖 Wi-Fi。配网失败不影响这里的调试。可选配网只在设备声明了 Wi-Fi 时出现。没有声明扫描时只能手填网络名称，页面不会为了扫描去改固件。发出配网请求不等于任务已经完成。

之后若要接入 Home Assistant 和房间卡片，按 [新手上手指南](../GETTING-STARTED_CN.md)，卡片仓库是 [mmwave-card](https://github.com/zomco/mmwave-card)。这个控制台不包含轨迹融合、桌面时间线或其他高级功能。
