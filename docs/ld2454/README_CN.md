# LD2454 控制

`Multi Target Mode` 开启时使用多目标跟踪，关闭时使用单目标跟踪。组件逐步等待
雷达的成功应答，再推进“进入配置 → 设置模式 → 结束配置”。开关显示雷达确认
的模式，不会仅因发出了命令就假定设置成功。

每一步等待应答最多 1.5 秒。超时或拒绝会记录日志，并尝试退出配置模式，
让目标上报恢复。已有配置事务执行时，新命令会被拒绝并记录忙碌警告；
可在该事务结束后重试。

协议依据：`ld2454-通信协议.pdf` 第 2.2.1–2.2.4 节和第 2.4 节。

回归测试：`python tests/test_ld2454_protocol.py`（需要 g++）。

### 仅使用多边形的软件边界过滤

提供定位坐标的雷达仅按房间多边形执行软件边界过滤。共享固件移除了 Zone Min/Max Distance 控件及对应持久化变量。为兼容旧配置仍接受 `distance_min`/`distance_max`，但旧值即使非零也不再参与检测判定。多边形为空时不执行软件边界过滤。雷达原生设置与坐标变换保持不变。
