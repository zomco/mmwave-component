## 若获授权时的一次短路径

不默认全片擦除。manifest 设了 `new_install_prompt_erase: true`。esp-web-tools 会先问 “Erase device”；复选框在源码模板里没有 `checked`，初始不勾选。不勾选就安装时，不发送全片擦除。

分区表里的 NVS 在 `0x390000`，长度 `0x70000`，位于 factory 镜像之外。factory 镜像从 `0x0` 写到 `0x181C50`，覆盖 bootloader、分区表、`0x9000` 的 otadata、`0xb000` 的 phy_init 和 app0。因此：不勾选擦除也不能保证旧 Wi-Fi 设置还在；若现有固件把配置放在 `0x9000` 一带，那段会被这次写入覆盖。现在没有 NVS 备份，不打开端口也做不出备份。

计划中的试写字段是 `install.x_cm`：数值，-2000 到 2000，步长 1 cm，host 域，不要求重启。先读原值，只改 1 cm，读回一致才算保存；正常重启后再读，然后写回原值。原值现在未知，不沿用旧 COM9 的 30。
