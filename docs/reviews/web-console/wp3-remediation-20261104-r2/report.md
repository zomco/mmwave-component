# WP-3 配置状态整改自检（R2-A / R2-B）

日期：2026-11-04。这是实现方自检，不是独立复核，也不是发布通过。

## 结论

上一轮 R1、直接 R2 和 R3 保持不动。本轮只改配置基线：

- 干净保存后再重连或重新握手，新读到的配置会替换草稿和基线。用户只改一项时，提交只带这一项。
- 有未保存修改时，设备侧变化不会静默覆盖，也不会把没改过的旧值写成新意图。页面进入冲突，必须先重新读取再编辑。
- 结果未知的保存在重连后仍保留原 op_id、基线版本和改动。新快照不能清掉它，也不能自动重发。
- 普通重新读取中途断开或读失败，只显示读取失败，不显示“保存已确认”。真正收到持久化确认后的读回失败，仍保留保存确认。提交应答丢失仍是 unknown。

没有改协议、固件 CAS、错误码、TTL 或坐标约定。没有提交、推送、烧录，也没有打开 COM3 或 COM9。D-03 仍只是 CLI 上传退出后的另一次连接，网页安装器没有验证。
